# 💧 یادآور قطره چشم — راهنمای نصب

برنامه‌ای که بر اساس نسخه‌ی پزشک (بتامتازون و کلوبیوتیک)، در هر روز و در ساعت‌های مقرر به گوشی یادآوری می‌کند که در هر چشم چه قطره‌ای بریزد.

---

## چطور کار می‌کند؟

```
GitHub Actions (هر ۱۵ دقیقه، در ابر) ──► ntfy.sh (رایگان) ──► اعلان روی گوشی
        │                                                        (حتی با قفل بودن گوشی)
        └─ ساعت/تاریخ تهران را حساب می‌کند و فقط اگر نوبتی باشد پیام می‌فرستد
```

- **زمان‌بند:** GitHub Actions هر ۱۵ دقیقه اجرا می‌شود، زمان حال تهران (UTC+3:30) را محاسبه می‌کند و فقط اگر در آن ساعت نوبت قطره وجود داشته باشد، پیام می‌فرستد. کامپیوتر شما لازم نیست روشن باشد.
- **انتقال اعلان:** ntfy.sh — سرویس رایگان بدون حساب. از ایران **بدون VPN** کار می‌کند (تست شده).
- **برنامه روی گوشی:** یک اپ تحت وب (PWA) که نصب می‌شود، آفلاین کار می‌کند، جدول امروز و هفته‌ی فعلی را نشان می‌دهد و دکمه‌ی «انجام شد» دارد.
- فایل `schedule.json` منبع واحد برنامه است: هفته‌ها، ساعت‌ها و قطره‌های هر چشم. اگر نسخه تغییر کرد فقط همین فایل را ویرایش کنید.

---

## مرحله ۱ — ساخت حساب و مخزن (ریپازیتوری) گیت‌هاب

1. به [github.com](https://github.com) بروید و یک حساب رایگان بسازید (حدود ۵ دقیقه).
2. بعد از ورود، دکمه‌ی **New** (کنار «Repositories») را بزنید.
3. نام مخزن را بگذارید: `eye-drop-reminder`
4. **Public** را انتخاب کنید (مهم: GitHub Pages برای حساب رایگان فقط روی مخزن عمومی فعال است). نگران نباشید — نگرانی امنیتی اینجا کم است و در انتهای همین راهنما توضیح داده شده.
5. «Add a README file» را **تیک نزنید** (README خودمان را آپلود می‌کنیم).
6. **Create repository** را بزنید.

## مرحله ۲ — آپلود فایل‌ها

### روش ساده (از طریق وب — پیشنهادی)
1. در صفحه‌ی مخزن جدید، روی **Add file → Upload files** کلیک کنید.
2. پنجره‌ی اکسپلورر ویندوز را باز کنید و به پوشه‌ی `eye-drop-reminder` بروید.
3. **همه‌ی محتویات پوشه را انتخاب و بکشید** داخل صفحه‌ی آپلود گیت‌هاب (شامل پوشه‌های `.github` و `icons` هم — مطمئن شوید انتخاب شده‌اند).
   - اگر پوشه‌ی `.github` در درگ‌اند‌دراپ نیامد، آن را جداگانه آپلود کنید: اول داخل مخزن یک پوشه‌ی `.github` بسازید (Add file → Create new file → نام `.github/workflows/reminder.yml` را تایپ کنید → محتوای فایل را از کامپیوتر کپی-پیست کنید → Commit) و بعد بقیه را درگ کنید.
4. دکمه‌ی سبز **Commit changes** را بزنید.

> بعد از آپلود، این فایل‌ها باید در مخزن باشند:
> `index.html` ، `app.js` ، `sw.js` ، `manifest.json` ، `schedule.json` ، `icons/icon-192.png` ، `icons/icon-512.png` ، `.github/workflows/reminder.yml` ، `.github/scripts/remind.py` ، `README.md`

## مرحله ۳ — فعال کردن GitHub Pages (میزبانی برنامه)

1. در مخزن، به **Settings** بروید.
2. از منوی کناری **Pages** را انتخاب کنید.
3. در «Build and deployment» → «Source» گزینه‌ی **Deploy from a branch** را بگذارید.
4. Branch را `main` و فولدر را `/ (root)` انتخاب کنید → **Save**.
5. ۱ تا ۲ دقیقه صبر کنید. آدرس برنامه: `https://اسم‌کاربری‌شما.github.io/eye-drop-reminder/`
   (این آدرس را جایی یادداشت کنید.)

## مرحله ۴ — فعال کردن Actions (زمان‌بند)

1. به تب **Actions** در مخزن بروید.
2. اگر پیام «Workflows haven't been run yet» دیدید، از کنار دستی روی **«Eye Drop Reminder»** کلیک کنید و بعد **Enable workflow** را بزنید.
3. از این به بعد زمان‌بند خودکار هر ۱۵ دقیقه اجرا می‌شود. (فعال شدن کامل تا چند دقیقه بعد از اولین push طول می‌کشد.)

## مرحله ۵ — نصب روی گوشی خودتان (تست)

1. از کروم اندروید، آدرس برنامه (مرحله ۳) را باز کنید.
2. جدول امروز و هفته‌ی فعلی را می‌بینید — این نسخه الان فعال است، پس داده‌های واقعی را نشان می‌دهد.
3. دکمه‌ی **«فعال کردن اعلان»** را بزنید و اجازه‌ی نمایش اعلان را بدهید.
4. منوی کروم (⋯) → **Add to Home screen** → «Install». حالا مثل یک اپ روی صفحه‌ی گوشی است.

### تست ارسال واقعی اعلان
1. در گیت‌هاب به تب **Actions** بروید.
2. روی «Eye Drop Reminder» → دکمه‌ی **Run workflow** → تیک «send_test» را بزنید → **Run workflow**.
3. حدود ۱ دقیقه بعد روی گوشی خودتان یک اعلان **«💧 تست یادآور قطره چشم»** می‌بینید.
   - این یعنی کل زنجیره (ابر → ntfy → گوشی) کار می‌کند. ✅

## مرحله ۶ — نصب روی گوشی فرد دیگر

1. همان آدرس برنامه را در کروم گوشی او باز کنید (فرستادن لینک با واتساپ/اس‌ام‌اس کافی است).
2. دکمه‌ی **«فعال کردن اعلان»** را بزنید و اجازه بدهید.
3. **Add to Home screen** را بزنید.
4. تمام — حساب یا تنظیم دیگری لازم نیست.

> نکته: از امروز (شنبه ۱ مرداد/۱ اوت) که نسخه فعال است، هر دو گوشی در ساعت‌های مقرر یادآوری می‌گیرند. اعلان در قفل گوشی هم می‌آید.

## خاموش کردن اعلان (مثلاً بعد از پایان نسخه)

- داخل خود برنامه: دکمه‌ی **«خاموش کردن اعلان»** — فقط همان گوشی را ساکت می‌کند.
- یا در گیت‌هاب: تب **Actions** → روی workflow → منوی `⋯` → **Disable workflow** — برای همه قطع می‌شود.

## عیب‌یابی

| مشکل | راه‌حل |
|------|--------|
| برنامه باز نمی‌شود (خطای 404) | آدرس را بررسی کنید (حروف کوچک، بدون فاصله). چند دقیقه صبر کنید تا Pages ساخته شود |
| اعلان نمی‌آید | مطمئن شوید گوشی اینترنت دارد و «فعال کردن اعلان» را زده‌اید؛ در تنظیمات گوشی اجازه‌ی اعلان کروم را بدهید؛ اعلان‌های برنامه را چک کنید |
| اعلان از قبل می‌آید | GitHub Actions هر ۱۵ دقیقه اجرا می‌شود و گاهی چند دقیقه تأخیر دارد؛ معمولاً در همان دقیقه‌های اولیه‌ی نوبت می‌رسد |
| «تست» فرستادم ولی نیامد | تب Actions را باز کنید و نتیجه‌ی آخرین run را ببینید (سبز = موفق). اگر قرمز بود، روی آن کلیک کنید و متن خطا را بفرستید برای من |
| هفته را اشتباه نشان می‌دهد | گوشی زمان/منطقه‌ی تهران را دارد؟ برنامه از تاریخ گوشی استفاده می‌کند |

## نکته‌های فنی و حریم خصوصی

- **مخزن عمومی:** چون Pages رایگان فقط روی مخزن عمومی است، مخزن عمومی است. نام کانال اعلان (در `schedule.json`، کلید `topic`) مثل یک رمز عبور است. چون این نسخه فقط ۴ هفته است و داده‌ی حساسی ندارد، ریسک ناچیز است. اگر خواستید بعداً کانال را عوض کنید: در `schedule.json` یک `topic` جدید بگذارید، push کنید و روی هر دو گوشی دکمه‌ی «خاموش» و دوباره «فعال» را بزنید.
- **اعلان وب پوش** از طریق سرویس گوگل (FCM) تحویل می‌شود و به Google Play Services روی گوشی نیاز دارد (تأیید شد موجود است).
- **هر هفته یک بار برنامه را باز کنید** تا اشتراک اعلان همیشه تازه بماند (کروم ممکن است اشتراک‌های خیلی قدیمی را غیرفعال کند).
- اگر نسخه‌ی پزشک تغییر کرد: `schedule.json` را ویرایش کنید، push کنید و روی گوشی‌ها برنامه را باز کنید — همه‌چیز خودکار به‌روز می‌شود.
- **این برنامه جایگزین توصیه‌ی پزشک نیست.** در صورت هر شک با پزشک خود مشورت کنید.
